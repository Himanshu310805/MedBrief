# MedBrief — Medical Report Summarizer

MedBrief is a full-stack NLP application that extracts, analyzes, and summarizes medical reports into clear and structured summaries.

It supports:
- PDF, image, and text input
- OCR for scanned medical documents
- Medical entity extraction
- Extractive and abstractive summarization
- Faithfulness verification
- ROUGE-based evaluation
- User authentication and report history
- PDF report generation

## Tech Stack

**Frontend:** React, Vite, CSS  
**Backend:** Python, FastAPI  
**NLP:** spaCy, ScispaCy, NLTK, TextRank, BART/DistilBART  
**OCR:** Tesseract, PyMuPDF, OpenCV  
**Database:** PostgreSQL with Supabase
